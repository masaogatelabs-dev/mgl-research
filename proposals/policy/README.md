組織をまたいでAIに仕事を任せるとき、開発者、提供者、利用組織、基準を定める主体、独立評価を担う主体に、どの責務を割り当てるかを提案します。権限付与と監督に加え、事故後の調査・救済、異議申立て、プライバシー、小規模事業者の導入負担を扱います。

本ページは提言の概要です。記載しているのはMGLが検討を提案する制度案です。共通ID **P-01〜P-08** に対応する技術条件と検証計画は、対になる技術提言で扱います。
