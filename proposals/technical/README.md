AIが技術的にできることと、委任された操作権限を分けます。再委任の範囲を確かめ、影響の大きい操作はエージェントから独立した制御点で認可・実行制御し、判断と実行結果を証跡から照合する構成を提案します。停止、再審査、再認可による復帰も対象です。

本ページは、参照構成と検証計画を示す技術提言の概要です。統合構成の有効性は検証課題として扱います。共通ID **P-01〜P-08** の制度上の根拠と役割分担は、対になる政策提言で扱います。
