## 実行制御と証跡

ファイルを更新する直前に、要求された操作と対象が委任範囲に入るかを照合します。範囲外なら、実行点で更新を拒否する設計です。

更新を行う側とは別の経路で、試行前後のファイル内容を観測します。操作IDで要求、許可・拒否の判断、観測結果をひもづけることで、第三者が同じ試行の記録を照合できます。二時点の比較で確認できる範囲と、試験の判定条件は検証計画に記載しています。

公開状況は参照設計と検証計画の段階です。検証計画の実測結果は未掲載です。
