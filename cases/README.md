# 事案分析・適用例

**日本語** · [English](README.en.md)

個別事案を出発点に、MGLのどの研究が関係するか、制御をどこに置くか、何を証拠に効果を判定するかを整理します。各記事では、**出典で確認できる事実、MGLの設計提案、試験計画、公開できる実測結果**を区別します。

## 準備中｜正規アカウントが悪用されたとき、どこで操作を止められるか

リモートIT業務におけるなりすまし事案を手掛かりに、ログイン後の操作を委任範囲に制限する設計を考えます。検証案では、隔離した環境で許可範囲内と範囲外の操作を比較し、認可判断と対象の試行前後の状態を別々に確かめます。事案記事の本文は準備中です。公開できる実測結果が得られた場合は、検証条件とともに掲載します。
