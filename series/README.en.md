# A Three-Stage Study on Building a Safe AI Society

[日本語](README.md) · **English**

This series examines how institutions developed to support road safety and uses those functions to derive requirements and a reference design for a society in which AI can act on people's behalf and interact with external systems. This page introduces the series. The full papers and annex are in preparation for public release.

| Reading order | Role in the series |
| --- | --- |
| **Paper 001 · Historical Evidence** | Examines institutions such as registration, qualification, and periodic inspection to identify functions worth considering in other domains |
| **Paper 002 · Requirements Engineering** | Translates those functions into requirements for identity, delegation, evidence, revocation, recovery, and related areas |
| **Paper 003 · Reference Architecture** | Maps the requirements to trust boundaries, runtime control points, evidence, and verification tasks |
| **Integrated series v1.1 · Security Annex** | Uses examples such as prompt injection and excessive authority to explain which controls address which stages |

For example, the institutional ability to revoke a qualification informs a requirement to revoke authority delegated to AI. The reference design turns that requirement into a verification question: can a subsequent action be denied at runtime?
