## 01 公開の異論 式8.19と式10.19

**開始時の指示と課題の出所。** 政夫の依頼は、フォーラムで議論された論文を査読することだった。照合した二つの論点は、Bastounis・Circelli・Hansenによる原稿とLeanの比較、およびHuntによる式(10.19)の公開反例報告に由来する。元の依頼から各争点を選ぶまでの個別発言の出所は、現存する査読記録では未確認。 [原稿とLeanの比較 §3–4](https://arxiv.org/html/2610.08144v1#S3) · [Huntの報告 §4–5](https://falsegreen.com/papers/paperA.pdf)

**仮定・試行・結果。** 式(8.19)では二次元トーラス上の平均ゼロの滑らかな入力 $F$ を取り、$N=v_t\cdot\partial_y$ の逆を非零モード $k$ ごとに $\widehat F(k)/(2\pi i v_t\cdot k)$ と書く。(6.7)で逆分母は $O(1+|k|)$。絶対値が最大の座標方向に $m+4$ 回部分積分し、出力の $m$ 階微分を加えると各項は $O((1+|k|)^{-3})$ になる。二次元では半径 $n$ の単位幅の殻に $O(n)$ 個の格子点があるので総和は収束する。原稿の $C^{m+4}$ 評価を再導出した。比較対象のLean宣言の仮定は $m+5$ 階で、評価の表記に差がある。 [原論文 (6.7)、(8.19)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=95) · [Leanの対応宣言](https://github.com/openai/NavierStokesAndEuler/blob/f9e8bc5b38b6e212696e8a30e3e91517af887bbd/NavierStokes/SmoothFamilyTorusInverse.lean#L1059-L1080)

式(10.19)では $\phi_R(x)=\phi(x/R)$、$0\le\phi_R\le1$、$\chi_R=\phi_R^8$、$B_R=\|\phi_R^4w\|_6$ とする。公開反例報告は冪を別の半径のカットオフとして扱っていた。原稿の定義で連鎖律を使うと、
$$
w\cdot\nabla\chi_R
=\frac{8}{R}\phi_R^3(\phi_R^4w)\cdot(\nabla\phi)(x/R).
$$
従って $B_R=0$ ならこの流束の因子はゼロ。反例報告の構成は原稿の定義のもとで $B_R=0$ と非零流束を両立できない。圧力流束の評価も再導出した。局所項は $L^{3/2}$ で $C_T(B_R+1)$、交換子は $L^{4/3}$ で $C_TR^{-3/4}$。$\phi_R^3w$ の $L^3,L^4$ 評価をそれぞれ組み合わせると、
$$
\left|\int\pi w\cdot\nabla\chi_R\right|
\le C_T R^{-1}(B_R+1)B_R^{1/2}
    +C_TR^{-7/4}B_R^{3/4}.
$$
ここで $C_T$ に差分速度の一様な $L^2$ 上界を含めた。 [原論文 (10.17)–(10.19)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30eaf8a9a/navier-stokes.pdf#page=122) · [公開反例報告](https://falsegreen.com/papers/paperA.pdf#page=5)

**当時の判定・次の課題。** この二つの争点の検証を完了し、論文全体は保留した。残る課題は、逆演算を組み込んだ命題9.6の反復と局所場への接続。 [工程02へ](#stage-02)

**AI査読者の着眼点。** 圧力流束の争点は、カットオフの記法をそろえたところで、反例が必要とする二つの条件を直接照合できた。

## 03 定理4.6の主プロファイルと応力

=\frac{305719}{1152000}>0.265
\quad (s=41/20).
$$

## 04 付録AとBの中間区間

**開始時の指示と課題の出所。** 前報で保留した中間区間を追査読。工程開始時の指示の逐語記録は未確認。チャッピー3号は、一様な下界が小さくなりやすい箇所、パルスの増加側の傾き、選ぶパラメータの順序を照合した。

$$
Q_s'+(1-\lambda)Q_s
=\lambda-h+c_\eta-\lambda L\bar k(0)e^{-y}.
$$
積分因子で解くと、定数入力と初期値の寄与に $-L\bar k(0)e^{-(1-\lambda)y}(1-e^{-\lambda y})$ が加わる。これで $L\bar k(0)<1/2$ を使う比較下界の符号を確かめた。パルス中は応力の方向を決める比 $w=N_s/(EQ_s)$ と傾きの項を残す。$a,b_s$ をせん断係数とすると、式(A.24)の十分条件は $a-b_s w>0$、$2b_s w+b_s^2/a+(a-2)w^2<2$。傾きを含む比較に現れる $-2R^2+2.41R$ と $-3.5R^2+4.82R$ の実数全体での最大は $58081/80000<0.74$ と $58081/35000<1.68$。先行評価による一様誤差をこの余裕で扱えることを点検した。ここで $R$ は比較多項式の実変数。 [原論文 (A.24)–(A.30)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=134)

**開始時の指示と課題の出所。** 政夫の継続指示を受け、前報で示した補題10.2・10.3をチャッピー3号が再導出した。入力は定理3.1の局所場の正則性、原点近傍での残差の減衰、および外部の熱流である。

**試行・結果。** $t<1$ で局所場を空間と時間のカットオフ $c$ で局所化する。局所速度を $\nabla\times\boldsymbol A+B e_\theta$ と書き、局所化後の速度を $\nabla\times(c\boldsymbol A)+cB e_\theta$ とすれば、発散ゼロを保てる。外力 $f$ はこの速度と局所化した圧力の運動方程式の残差で定義する。原点付近では残差が任意次数でゼロに近づく。軸方向座標が非零の場所では $q$ に正の下限がある。$z=0$ で半径が正の場所には外部熱流の積分表示を使える。固定の空間台の上でこれらを合わせ、すべての固定階数について
$$
F_j(x)=\lim_{t\uparrow1}\partial_t^j f(x,t)
$$
とその空間微分の一様な極限を得る。 [原論文 命題10.1、補題10.2](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=117)

外部熱流を $K(r,\tau)=c_\infty(r^2/2)^{-A}H(4\tau/r^2)$、$\tau=1-t$、$A=1/2+h$ と書く。$H(Z)$ の積分核 $e^{-v}v^h(1+Zv)^{-h}$ は、固定の $j$ 階微分ごとに $C_j e^{-v}v^{h+j}$ で抑えられる。圧力の積分 $-\int_r^\infty K(\varrho,\tau)^2\,d\varrho/\varrho$ の $j$ 階時間微分の被積分関数は $C_j\varrho^{-3-4h-2j}$ で抑えられる。半径に正の下限がある場所で、この可積分な上界が極限と微分の交換を支える。 [原論文 (10.7)–(10.8)、(A.32)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=119) · [原論文 外部熱流の積分核](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=138)

時刻1の後は $\sigma=t-1\ge0$ として $\sum_{j\ge0}\chi_0(b_j\sigma)\sigma^jF_j/j!$ を使う。$\chi_0$ は0の近くで1、引数が1以上で0。各項の $m$ 階時間微分は台の上で $b_j^{m-j}$ に比例する上界を持つ。$m+|\alpha|\le\lfloor j/2\rfloor$ の有限個を一度に $2^{-j}$ 以下にするよう $b_j$ を選べる。各固定階数で微分後の級数が一様収束し、$\sigma=0$ では $j=m$ の項だけが寄与するため、右側の微分は左側の $\partial_x^\alpha F_m$ と一致する。外力は固定の空間台を持ち、時刻2以後はゼロになる。積分核の時刻側微分と級数の係数選択は0〜8階でも検算した。全階数での結論は上の一様収束に基づく。 [原論文 補題10.3、(10.11)–(10.12)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=120)

**当時の判定・次の課題。** 局所場を入力として外力の延長、エネルギー評価、周期版への接続を支持した。論文全体の判定を保留し、背景場と波を組み立てる第5〜7節で、後の反復に必要な入力が満たされるかを追った。 [工程06へ](#stage-06)

## 07 第8節の圧力再構成と積分欠損

**開始時の指示と課題の出所。** 政夫の「次の工程お願いします🥺👍」を受け、チャッピー3号が前報で挙げた (8.6)–(8.9) と (8.12)–(8.17) を再導出した。

**仮定・試行・結果。** $R$ は正規化半径、$Y$ は補助トーラス、$Z$ は正規化軸方向座標とする。半径逆演算は入力の滑らかなゼロ延長を使う。$e=0,1,2$ について、左からの原始積分から全積分 $J(R^ef)$ に切り詰め関数 $\chi_m$ を掛けたものを引く。環の内側では左積分がゼロ、外側では全積分と一致するので、補正場の台が閉じる。積分は補助トーラス上の半径方向のずれも含む。対応する微分を $D_r$ と書けば、
$$
(D_r+e/R)T_ef=f-R^{-e}(\partial_R\chi_m)J(R^ef).
$$
$\int R^e\langle f\rangle_Y\,dR=0$ のとき全積分のゼロFourierモードは消える。残るモードは、補題8.2の積分経路に沿って $p$ 回部分積分すると $M^{-p}$ を得る。固定した出力微分階数に対して必要な入力微分は有限で、$M^{-1}\lesssim\varepsilon^{\kappa_s}S_*^{\rho_g}$ を使えば切り詰め誤差を任意の $q$ の正のべきで抑えられる。補助変数に依存しない入力では、同じ重み付き積分条件の下で誤差は点ごとにゼロ。 [原論文 補題8.2、(8.6)–(8.10)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=90)

$g_r$ を半径方向の残差源、$P=\int\langle g_r\rangle_Y\,dR$、$\int\rho\,dR=1$、$p_m=T_0(g_r-\rho P)$ とする。原論文の式(8.13)から $\partial_R\langle p_m\rangle_Y=\langle g_r\rangle_Y-\rho P$。台の境界で項が消えるため、
$$
\int R\langle p_m\rangle_Y\,dR
=-\frac12\int R^2\langle g_r\rangle_Y\,dR+c_\rho P,
\qquad c_\rho=\frac12\int R^2\rho\,dR.
$$
二つの速度モーメントがゼロという原論文の仮定を入れ、周方向に $R^2$、軸方向に $R$ を掛けると、時間微分と軸粘性はそのゼロ積分の微分となり、半径方向の発散も境界で消える。残る周方向の積分欠損を $J_\theta$、軸方向の積分欠損を $J_z$ とすると、軸方向には圧力由来の $c_\rho P$ が加わる。
$$
\int R^2\langle E_\theta\rangle_Y\,dR=\varepsilon\partial_ZJ_\theta,
\qquad
\int R\langle E_z\rangle_Y\,dR=\varepsilon\partial_Z(J_z+c_\rho P).
$$
ここで $J_\theta=\int R^2\langle Gv+V\gamma+\gamma v+W_{z\theta}\rangle_Y\,dR$、$J_z=\int R\langle2G\gamma+\gamma^2+W_{zz}\rangle_Y\,dR-\tfrac12\int R^2\langle g_r\rangle_Y\,dR$。$G,V$ は背景の軸・周速度、$\gamma,v$ は対応する平均補正、$W_{ab}$ は波の速度成分の積を物理角度で平均したもの。物理量とチャートの間で $R^e\,dR=Q^{-(e+1)/2}r^e\,dr$ を用いると、$J_z$ と $c_\rho P$ はどちらも $Q^{2A-1}$ の規格化を持つ。 [原論文 (8.11)–(8.17)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=92)

**検算例。** $\rho=(q/Q)^{-1/2}\widehat\rho(R/\sqrt{q/Q})$ なら $c_\rho=(q/Q)\widehat c_\rho$。末尾の多項式例では $q/Q=1+Z$、$P=1$、$\langle g_r\rangle_Y$ は $Z$ に依存しない。$\partial_ZP=0$ でも圧力積分の微分は $41/36$ になる。この例で積の微分の取り落としを検出できる。一般の滑らかな入力に対する根拠は上の部分積分である。

**考察・検算・絞り込み。** 確認した問いは、軸方向微分で $c_\rho$ 自体の変化が残るかである。積全体を微分する式 $\partial_Z(c_\rho P)$ と、係数を外に出した式 $c_\rho\partial_ZP$ を比較するため、検算では $P=1$ に固定し、補正関数の尺度 $q/Q$ だけを動かした。前者には $P\partial_Zc_\rho=41/36$ が残り、後者の値はゼロになる。この差で、二つの式が異なる条件を特定できる。一般式では部分積分から積全体が残ることを確かめたため、次に調べる箇所を、第9節がこの積と軸方向微分の因子を保持しているかに絞った。 [原論文 (8.13)、(8.15)–(8.16)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=93)

**当時の判定・次の課題。** 第8節の補正が命題9.5・9.6に渡る条件を確認し、主定理の判定は統合照合まで保留した。次は、(8.16) の積全体の微分が (9.12) の重み付き残差の次数評価に使われることと、その評価が局所場と外力の構成へつながることを確認する。 [原論文 (9.12)](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf#page=108) · [工程08へ](#stage-08)

**AI査読者の着眼点。** $P$ を一定にしても圧力の積分が変わる例が、積全体を微分する必要性を短い計算で示してくれた。

工程07の例では $\widehat\rho(x)=140(x-1)^3(2-x)^3$ を $1\le x\le2$ で用い、それ以外でゼロとする。$s=x-1$ と置くと、二つの数は $\int\widehat\rho(x)\,dx$ と $\frac12\int x^2\widehat\rho(x)\,dx$ から求まる。工程07のように $q/Q=1+Z$ と $P=1$ を入れると、後者の $41/36$ が積の軸方向微分に現れる。

<a name="verification-code"></a>

### 検算コード

```python
import argparse
from fractions import Fraction as F
from math import comb, factorial

KAPPA = F(1, 100_000)


def residual_orders():
    # At the entry B = 0.7. The terms depending on B increase later.
    B = F(7, 10)
    wave = min(F(1, 2) - 4*KAPPA, F(2, 5) - KAPPA,
               F(1, 2) - 2*KAPPA, B - 3*KAPPA)
    mean = min(F(17, 100), 1 - 4*KAPPA)
    defect = F(9, 10) - 4*KAPPA
    result = (wave, mean, defect)
    assert all(gain > F(1, 10) for gain in result)
    return result


def axis_series():
    s = F(41, 20)
    return (sum((-s)**j / (factorial(j) * factorial(j + 1))
                for j in range(4)),)


def transition_quadratics():
    coefficients = ((F(2), F("2.41")), (F("3.5"), F("4.82")))
    return tuple(b*b / (4*a) for a, b in coefficients)


def force_jets():
    # Near zero the cutoff is identically one. Coefficients are padded
    # with zeros so every derivative below can be evaluated at zero.
    matches = 0
    for j in range(9):
        coefficients = [F(0)] * 9
        coefficients[j] = F(1, factorial(j))
        for m in range(9):
            assert coefficients[0] == int(j == m)
            matches += 1
            coefficients = [k * coefficients[k] for k in range(1, len(coefficients))]
    return (matches,)


def initial_orders():
    H0 = 1 - KAPPA
    wave = min(1 - 3*KAPPA, 1 - KAPPA, H0)
    mean = min(F(1, 2) + (1 - KAPPA) - KAPPA, 2 - KAPPA)
    defect = H0 + F(9, 10) - 2*KAPPA
    assert wave > F(7, 10) and min(mean, defect) > F(6, 5)
    return (wave, mean, defect)


def pressure_moment():
    # Integrate x**power * rho_hat(x) using s = x - 1 on [1, 2].
    def moment(power):
        return sum(F(140 * comb(power, i) * (-1)**j * comb(3, j), 4 + i + j)
                   for i in range(power + 1) for j in range(4))
    return (moment(0), moment(2) / 2)


CHECKS = {
    "02": (residual_orders, (F(39999, 100000), F(17, 100), F(22499, 25000))),
    "03": (axis_series, (F(305719, 1152000),)),
    "04": (transition_quadratics, (F(58081, 80000), F(58081, 35000))),
    "05": (force_jets, (81,)),
    "06": (initial_orders, (F(99997, 100000), F(74999, 50000), F(189997, 100000))),
    "07": (pressure_moment, (1, F(41, 36))),
}

parser = argparse.ArgumentParser()
parser.add_argument("stage", nargs="?", choices=CHECKS)
args = parser.parse_args()
for stage in [args.stage] if args.stage else CHECKS:
    check, expected = CHECKS[stage]
    actual = check()
    assert actual == expected, (stage, actual, expected)
    print(f"{stage}: PASS " + ", ".join(map(str, actual)))
```
