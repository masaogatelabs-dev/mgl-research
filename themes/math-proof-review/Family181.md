# エルデシュ–ガライ閉路分解予想の査読途中報告

Masao Gate Labs · OpenAI Math Family 181 · 途中報告 公開版 v0.1.0 · 2026-11-14 JST · MGL-REF-014

## 対象と現在の判定

OpenAIの2026年9月24日付固定原稿を対象にしました。主定理1.1（p. 1）は、n 頂点の有限単純無向グラフの辺を、高々 Cn 個の単純閉路と単辺へ重複なく分割できると主張します。C はグラフに依存しない定数です。**固定原稿の技術査読は保留中です。** 保留箇所は補題3.1（pp. 5–8）の式(3.6)で、主定理1.1と系1.2への依存が残ります。

## 式(3.6)で保留した推論

補題3.1では、h をカット展開の下限、ℓ を経路長の上限、k を端点負荷の上限、b をチームの大きさの上限、z を要求ごとの禁止頂点数の上限とします。式(3.2)の印刷された仮定は h ≥ 64ℓ²(k + b) + z です。式(3.6)では 4[z + (k + b)ℓ²] ≤ h/16 としています。後続の式(3.8)で使う |Wₚ| ≤ h/4 も、z が大きい場合には印刷された仮定から従いません。Wₚ は要求 p の両端点を除いた、削除対象の頂点集合です。

MGLは r = 2⁴⁰ 頂点の完全グラフで h = r/2、k = b = 1、ℓ = 53,792 とし、z = 179,377,668,096 を得ました。式(3.2)は等号で成立しますが、z は h/4 = 137,438,953,472 を上回ります。端点を避けた禁止集合を取ると |Wₚ| ≥ z です。この例が反証するのは証明中の上界への推論です。経路の存在自体はこの例では判定していません。

## MGLの修正案と二つの適用箇所

MGLが検討した修正案は、式(3.2)の z を 4z に強め、式(3.6)を |Wₚ| ≤ z + 4bℓ² ≤ h/4 に置き換えることです。4z + 16bℓ² ≤ 4z + 64(k + b)ℓ² から後半の不等式が従います。式(3.8)の成長評価が使う h/4 と、辺の削除数の評価が使う h ≥ 64kℓ² を確保できます。

| 原論文の適用箇所 | 修正案で確認した範囲 |
| --- | --- |
| 補題4.3（pp. 12–13） | z = 0 のため、係数の変更によって仮定は変わりません。 |
| 補題6.2（p. 21、適用 p. 24） | z = 2B₀、B₀ = D⁰·³⁰、h = D⁰·⁹⁰/4。変更後の 4z = 8D⁰·³⁰ と、残る項 64ℓ²(k + b) = O(D⁰·⁵⁴(log D)⁴) はともに o(h) です。十分大きい D では強めた仮定を満たします。 |

## 確認範囲と未確認事項

二つの適用箇所では、強めた条件が足りることを確認しました。強帰納法では再帰入力が個々に小さくなる条件と、重複する頂点の総数の扱いを点検しました。補題3.1の印刷された一般形の証明、著者確認、独立した第三者の査読・追試、MGLによるLeanの実行は未確認または未実施です。OpenAIは主定理に対応する形式化範囲を別途示しています。
