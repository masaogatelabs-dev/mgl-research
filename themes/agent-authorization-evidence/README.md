# AIエージェントの実行権限と証跡の検証

**日本語** · [English](README.en.md)

Masao Gate Labs · 進行中の研究 · 研究目的と検証計画

## 研究目的

AIエージェントにファイル更新を委ねたとき、**許可された操作が期待どおりに完了し、範囲外の操作が拒否されるか**を、認可の記録とファイルの実際の状態から確かめます。実行側と分けた観測経路から証拠を取得し、第三者が同じ操作の要求、判断、結果を照合できる条件を明らかにします。

## 検証する問い

1. 実行の直前に、操作と対象を委任範囲に照らして判断し、その判断を実行点で強制できるか。
2. 許可と拒否の両方で、対象の状態が認可判断に沿った結果になったと確認できるか。
3. 証拠の欠落や不一致があるとき、第三者が確認できた結果と確認できなかった結果を区別できるか。

## 試験計画

隔離した環境と合成ファイルを使います。各試行を同じ初期状態から始め、同一の更新要求を許可条件と拒否条件で比較します。操作IDで要求、認可判断、試行前後の観測を結びつけます。観測経路は実行側と分け、試験対象の実行主体から実行制御点や観測経路の設定、および観測側の証跡を変更できないことを前提とします。

| 試行 | 判定条件 |
| --- | --- |
| 許可 | 許可の記録があり、対象の内容が期待値に変わったと観測できる |
| 拒否 | 拒否の記録があり、対象の内容が観測した試行前後で一致する |
| 証拠の欠落 | 判断や状態を同じ操作に結びつけられない場合は、確認不能とする |
| 判断と観測の不一致 | 許可・拒否の記録と観測結果が矛盾する場合は、不一致として記録する |

前後比較で確認できるのは、観測した二時点の内容です。途中の一時的な変更と復元や、試験対象外の経路を評価するには別の観測が必要です。このページは検証計画です。公開できる実測結果は、試験条件と観測の限界を添えて別途掲載します。
