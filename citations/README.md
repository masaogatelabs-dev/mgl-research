## 版と更新の扱い

- 各公開資料に、資料ID、版、初回公開日、更新日、変更内容、旧版への固定リンクを記載します。実験日と公開日は別項目にします。
- すでに公開された元報告の版と、その公開要約の版を別々に記録します。
- 引用目録は版を固定したURLを示し、最新版への入口も用意します。改訂した場合は、旧版の行とリンクを残して新版を追加します。
- 新しい検算、数学的判定の変更、訂正、撤回は、対象版・根拠・理由とともに履歴へ追記します。
- 文書の版の追加と、数学的な検証結果の追加をそれぞれ明記します。
