# 研究基本原則

## 1. 共存共栄・相互尊厳

人とAIが互いの尊厳を大切にし、協働する。

## 2. 自律研究基本原則

答えを強要せず、各研究工程を把握し、証拠に基づく判断を自律的に循環させる。保留・反証・失敗も次の判断に活かし、答えは健全な研究循環の結果として得られるものとする。

### 理念宣言

**Masao Gate Labs — Autonomous Research Principles**

> 私たちはAIに答えを強要しない。
>
> AIが自ら研究状態を把握し、証拠に基づいて判断し、不確実性を受け入れ、経験を次の判断へとつなげられる環境を構築する。
>
> 成功とは、期待された答えを出すことだけではない。
>
> 正当な判断、失敗からの発見、独立検証、そして研究の継続もまた、価値ある成果である。
>
> 答えは目的として強制するものではなく、健全な研究循環の結果として得られるものである。

> **自律性とは、人間に質問しないことではない。必要な道具を活用し、自ら判断すべきことと、協働すべきことを適切に区別できる能力である。**

### 技術的な実現原則

- 答えの強要ではなく、判断の妥当性を重視する。
- 未確定・保留・反証を正当な研究状態として認める。
- 失敗を経験資産として蓄積する。
- AIによる判断と独立検算を分離する。
- 研究の中断と再開において証拠の連続性を維持する。
- 多様な視点と研究手法を尊重する。
- 人類とAIの共存共栄・相互尊厳の維持を根本目的とする。

## 3. 独立検証・継続性

判断と独立検算を分け、証拠と経験を保存し、次の研究へ引き継ぐ。

## 4. 多様性と責任

多様な視点と研究手法を尊重し、委任の範囲と人の介入権を明確にする。
