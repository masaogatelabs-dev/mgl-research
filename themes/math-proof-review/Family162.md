# ライザー予想の釣り合い条件付き反例の技術査読

Masao Gate Labs · OpenAI Math Family 162 · 公開版 v0.1.0 · 2026-11-14 JST · MGL-REF-013

## 対象と査読結果

OpenAIの2026年9月27日付固定原稿について、主定理1.1と系1.2（p. 2）を確認しました。MGL内の技術査読は完了し、確認した範囲で結論を覆す欠陥は見つかりませんでした。

| 原論文の箇所 | MGLが確認した内容 |
| --- | --- |
| 主定理1.1（証明 §7） | 十分大きい各素数 q について、q + 1 個の部を持つ交差超グラフを構成します。各超辺は各部から1頂点を取り、各部には超辺に属する頂点がちょうど q + 1 個あります。全超辺と交わる頂点集合の最小サイズは q + 1 で、交差する場合に q 以下とする被覆予想に反します。 |
| 系1.2 | 超辺を完全グラフの頂点とし、共有頂点の部から辺の色を選びます。単色連結部分は共有する一つの超グラフ頂点に対応するため、被覆に必要な単色木は少なくとも q + 1 本です。一頂点を中心に各色の星を取ると上界も q + 1 本になります。 |

## 有限検算と一般論証

| 確認の種類 | 確認した内容 |
| --- | --- |
| 有限検算 | q = 5, 7, 11 で点と直線を列挙し、有限の中心を持つ直線束に関する局所の入射上界を照合しました。整数の計数条件は2,950通りを照合しました。 |
| 一般論証 | 平行線の併合・分割で部の大きさをそろえ、分割で離れた点対の交差を別方向の併合で保つ手順を確認しました（§2）。無限遠と有限の中心を分け、削除線の集中評価、候補選択の同時確率、有限中心での被覆排除を経て、全条件が同時に成立する正の確率を得る論証を確認しました（§§3–7）。 |

## MGLの局所的な改善所見

§2（pp. 7–8）で、中心を通る所定の併合相手のブロックが選ばれていないとします。束内のラベルが覆う点は高々 1 + B 個、束外の t ラベルは一つにつき高々2点です。原論文の ρq > 2(1 + B) と t ≤ ρq/4 から、必要な ρq 点には届きません。

占有点数とラベル数は整数なので、MGLはこの一段に限り、⌈ρq⌉ > 1 + B + 2⌊ρq/4⌋ でも同じ矛盾が得られると確認しました。q = 11、B = 2、ρ = 6/11 では必要な6点に対し上界は5点です。この数値例が示すのは局所計数の境界です。

## 未確認事項

原論文の素数下限は存在的です。検算した小素数での反例構成、改善所見を使った素数下限の引き下げ、独立した第三者の査読・追試、人間による査読、先行研究の網羅的照合、MGLによるLeanの実行は未実施です。OpenAIの形式化資料では、釣り合い条件付きの主定理に対応する範囲を参照できます。
