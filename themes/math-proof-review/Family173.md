## 補題3.1の短縮案を破る3頂点の例

補題3.1（pp. 6–10）の式(8)は、衝突を解消する削除数の上限を **|H| + q** とします。q は、衝突から定まる点の集合 Z のうち、削除後に残った要素に覆われない点の数です。MGLが査読中に検討した短縮案では、この q を省き、上限を **|H|** とします。

頂点は 0、1、2、弧は 0 → 1 と 0 → 2 の2本です。左の族 R = {(0,1), (0,2)}、右の族 C = {(1,0), (2,0)} とします。左の各要素は右の両要素と衝突するため、解消には最低2件の削除が必要です。原論文の定義では H = {(0,0)} なので、|H| = 1 だけを上限とする短縮案はこの例で破れます。

Z = {1,2} × {1,2} の4点は削除前にすべて被覆されています。片側の2件だけを削除すると、残った側が4点を覆うため q = 0 で、2 ≤ 1 は成り立ちません。両側の4件を削除すると q = 4 となり、4 ≤ 1 + 4 が成り立ちます。この削除で原論文の式(8)を満たします。

## 一般論証で確認した範囲

主定理では、命題2.1（pp. 3–5）が最小反例から必要な拡張条件を持つグラフを導き、命題4.1（pp. 10–12）がその存在を排除する接続を確認しました。命題4.1で枝刈りを適用する際には、対角要素が衝突せず保持される条件も点検しました。

補題3.1では、拡張二部グラフのマッチング上限 |Z| + |H| を導く階数の議論（補題3.2を含む）と、頂点被覆から式(8)を得る手順を確認しました。削除後にも被覆される |Z| − q 個の点は、頂点被覆の中でそれぞれ別の補助頂点を要します。被覆の上限からこの分を引くと、元の要素の削除数は |H| + q 以下となります（式(9)）。この手順は当初から衝突しない要素も保持します。

系5.1ではSeacrestの命題2、弧重みから頂点重みへの特殊化、逆向きグラフの行列が転置になることを用いた分離の議論を確認しました。系6.1では、有向三角形がなければ有向距離ちょうど2の頂点は非近傍になることから、三つの結論を導く手順を確認しました。
